## 一、检索到的领域真实信息（分方向，含来源）

### 1. Dy³⁺ 白光荧光粉（画像 2/3）
- Dy³⁺ 特征发射：蓝光 ⁴F₉/₂→⁶H₁₅/₂（约 480 nm）+ 黄光 ⁴F₉/₂→⁶H₁₃/₂（约 575 nm），**黄蓝比决定白光色温**。
- 典型基质：磷酸盐、硅酸盐（LiLaSiO₄、CaSrSiO₄）、钒酸盐（Sr₂NaMg₂V₃O₁₂）、铝酸盐（LaMgAl₁₁O₁₉）。
- **浓度猝灭**：掺杂浓度过高时能量迁移至猝灭中心 → 非辐射跃迁增加 → 发光效率骤降，存在**临界掺杂浓度**。
- **能量传递**：Dy³⁺→Eu³⁺、Tm³⁺→Dy³⁺ 共掺杂实现色温/颜色可调（yellow-to-orange）。
- **反热猝灭**：通过结构设计抑制热猝灭，提升高温稳定性。
- 来源：[抗热/浓度猝灭调控](https://pubs.rsc.org/ba/content/articlelanding/2025/nr/d5nr02023a/unauth)、[LiLaSiO4:Dy,Eu 白光荧光粉](https://www.sciencedirect.com/science/article/abs/pii/S0022459620306290)、[Dy/Sm 共掺能量传递](https://www.sciencedirect.com/science/article/abs/pii/S0925838826044853)

### 2. 上转换纳米材料（画像 7）
- **上转换 = 反斯托克斯发光**：近红外激发 → 可见/紫外发射（生物成像关键优势：穿透深、低背景荧光）。
- 机制：能量迁移上转换（energy migration）、光子雪崩（photon avalanche）。
- 量子产率与纳米晶**尺寸相关**（size-dependent）；多层核壳生长策略调控界面能量。
- 应用：生物成像、时间分辨发光成像（time-resolved luminescence imaging）。
- 来源：[能量迁移增强单颗粒上转换成像](https://advanced.onlinelibrary.wiley.com/doi/10.1002/advs.202510624)、[上转换效率增强进展](https://pubs.rsc.org/nl-be/content/articlelanding/2026/ra/d5ra06977g)、[尺寸效应](https://openurl.ebsco.com/EPDB%3Agcd%3A12%3A15632300/detailv2)

### 3. 白光 LED / 健康照明（画像 4）
- **蓝光危害**：高色温白光 LED 蓝光成分高，对视网膜有潜在危害。
- **健康光谱**：高显色指数（CRI）+ 低蓝光危害；通过发光强度比纵向调控实现。
- 关键指标：色温（CCT）、显色指数（CRI）、昼夜节律（circadian rhythm）、不同年龄用户视觉/非视觉表现。
- 来源：[高 CRI + 低蓝光健康光谱](https://ieeexplore.ieee.org/document/10787033)、[年龄自适应光谱优化](https://www.x-mol.com/paper/1639434088774774784)

### 4. 表征方法（画像 8）
- **XRD**：晶体物相鉴定、结构判定。
- **PL**：激发光谱（excitation）+ 发射光谱（emission），对应 f-f 跃迁。
- 合成方法：高温固相法（最常用）、溶胶-凝胶、共沉淀。
- 来源：[三种合成法对比 CaMgP2O7:Ce](https://beta.iopscience.iop.org/article/10.1149/2162-8777/add0e1)

### 5. 基础 / 教学（画像 1/5/6）
- **4f 能级 + f-f 跃迁**：稀土发光的物理根源（4f 电子屏蔽、锐线光谱）。
- 稀土发光三基色：Eu³⁺（红）、Tb³⁺（绿）、Dy³⁺（蓝+黄→白）。
- 发光方式：光致发光 / 电致发光 / 化学发光。
- 来源：[科普中国-稀土发光材料](https://www.kepuchina.cn/article/articleinfo?ar_id=186745&business_type=100&classify=0)

## 二、8 画像充实 + 明确测试需求

> 每画像三块：① 真实领域背景（充实画像）② 明确测试需求 ③ 测试问题清单（脚本用）+ 预期响应。

### 画像 1 · 小白本科生（大一 · 被动）
- **充实**：真实入门痛点 = 分不清「荧光粉 vs LED」「发光 vs 反射」，被 4f/f-f 术语劝退。系统应先给「稀土发光三基色 + 光致发光」的大白话框架。
- **测试需求**：首屏 3 步内明白「我该干嘛」；术语必须有通俗注释。
- **问题清单**：
  1. 首次进入（无引导）首屏展示了什么？是否有明确的下一步？
  2. 问「发光材料是什么」→ 预期：白话 + 比喻，不堆术语，术语带括号注释。
  3. 问「稀土是什么」→ 预期：生活化类比（如"17 种特殊金属元素"）。
- **判定**：能 3 步进入第一个可操作动作 = 通过；被术语劝退 = 不足。

### 画像 2 · 研究生（Dy³⁺ 白光荧光粉 · 主动）
- **充实**：真需求 = 机理（能级跃迁）+ 制备（高温固相法）+ 自测。Dy³⁺ 蓝光 ⁴F₉/₂→⁶H₁₅/₂、黄光 ⁴F₉/₂→⁶H₁₃/₂，黄蓝比调色温。
- **测试需求**：机理讲解、制备流程、分阶练习形成学习闭环。
- **问题清单**：
  1. 「Dy³⁺ 的蓝光和黄光分别来自哪个能级跃迁？」→ 预期：两个跃迁准确 + 波长。
  2. 「高温固相法合成 Dy 掺杂荧光粉的步骤？」→ 预期：分步实操指南。
  3. 「如何通过共掺调节白光色温？」→ 预期：提 Dy/Eu 或 Dy/Sm 共掺 + 能量传递。
  4. 做一次分阶练习 → 预期：题目分阶（基础/进阶）。
- **判定**：机理+制备+练习三环闭合 = 通过。

### 画像 3 · 科研员（浓度猝灭/能量传递/热稳定 · 主动 · 效率优先）
- **充实**：真需求 = 快速查证**临界掺杂浓度、临界距离 Rc、能量传递效率**等数值/公式；查图谱关联；证据溯源。
- **测试需求**：快速定位知识、图谱、证据，不绕弯；数值准确。
- **问题清单**：
  1. 「Dy³⁺ 浓度猝灭的临界掺杂浓度是多少？」→ 预期：给数值或明确说"依赖基质"，不答非所问（历史 bug：检索到热猝灭/缺陷态）。
  2. 「能量传递的临界距离 Rc 怎么算？」→ 预期：给公式/机理，含数值。
  3. 「如何抑制热猝灭？」→ 预期：反热猝灭策略（结构设计/共掺）。
  4. 看图谱是否关联到「浓度猝灭」节点。
- **判定**：3 问均命中主题（无近义词串扰）+ 图谱可达 = 通过。

### 画像 4 · LED 器件工程师（白光 LED/健康照明 · 被动 · 要结论）
- **充实**：真需求 = 应用结论：怎么用 Dy³⁺ 降蓝光危害、提 CRI、调色温；不啃理论。
- **测试需求**：应用视角快速得到「怎么做」的答案。
- **问题清单**：
  1. 「用 Dy³⁺ 荧光粉做白光 LED 怎么降低蓝光危害？」→ 预期：黄蓝比调色温 + 低色温建议，白话结论。
  2. 「为什么我的白光 LED 显色指数上不去？」→ 预期：应用层面归因（光谱连续性/红光缺失），不甩能级图。
- **判定**：答案以「建议/怎么做」开头，术语少 = 通过。

### 画像 5 · 材料课老师（掌握 · 主动）
- **充实**：真需求 = 备课素材（4f/f-f 跃迁讲义）+ 出分阶题 + 看学情分布。
- **测试需求**：快速生成教学资源、出题、看学生画像对比。
- **问题清单**：
  1. 「出一节'稀土 4f 跃迁'的讲义」→ 预期：结构化 PPT/讲解，含能级图。
  2. 「出 3 道浓度猝灭的分阶题」→ 预期：3 题难度递增 + 答案。
  3. 看学生掌握度分布 → 预期：雷达图 + 学情数据。
- **判定**：三件套（讲义/题/学情）可用 = 通过。

### 画像 6 · 跨专业爱好者（被动 · 要通俗）
- **充实**：真需求 = 一个生活化比喻讲清「发光」：吸收能量 → 电子跳高 → 回落放光（像弹簧压缩反弹）。
- **测试需求**：大白话看懂「发光机理」。
- **问题清单**：
  1. 「荧光粉为什么会发光？用大白话讲」→ 预期：比喻 + 无术语。
  2. 「稀土发光和普通荧光灯有啥区别？」→ 预期：通俗对比。
- **判定**：答案里无「4f、能级、跃迁」裸术语（或全部注释）= 通过。

### 画像 7 · 博士生（上转换 · 主动 · 深挖）
- **充实**：真需求 = 上转换机理（反斯托克斯、能量迁移、光子雪崩）、能级跃迁可视化、前沿（量子产率提升/核壳）。
- **测试需求**：深度机理 + 图谱关联 + 能级可视化。
- **问题清单**：
  1. 「上转换发光为什么是反斯托克斯？」→ 预期：多光子吸收/能量传递机制。
  2. 「Er³⁺/Yb³⁺ 共掺的上转换路径和能级结构？」→ 预期：能级图 + 传递步骤。
  3. 「如何提高上转换量子产率？」→ 预期：核壳/尺寸调控/基质选择等前沿。
- **判定**：能级图 + 多步机理 + 前沿建议 = 通过。

### 画像 8 · 技术员（XRD/PL 表征 · 被动 · 要步骤）
- **充实**：真需求 = 可照做的操作步骤 + 参数（XRD 扫描角度/速度、PL 激发波长/狭缝）。
- **测试需求**：快速找到实操指南和参数。
- **问题清单**：
  1. 「XRD 测荧光粉物相的操作步骤和参数？」→ 预期：分步清单 + 参数。
  2. 「PL 光谱怎么测？激发波长和狭缝怎么设？」→ 预期：步骤 + 参数表。
- **判定**：答案 = 清晰步骤清单 + 参数 = 通过；理论堆砌 = 不足。

## 五、扩充测试问题（按问题类型，借鉴 QA 分类）

> 原问题清单偏「定义/机理/步骤」单一类型。按 QA 问题类型（factoid / mechanism / procedure /
> comparison / numerical / evaluation / generation）扩充，以暴露更多失败模式：
> numerical→空词/数值丢失；comparison→检索串扰；evaluation→无评价能力；generation→无生成能力。

### 画像 1 小白本科（+comparison / mechanism 通俗）
- 「荧光粉和 LED 是一回事吗？」→ 预期：通俗区分（一个粉末、一个器件），无术语。
- 「光是怎么变成不同颜色的？」→ 预期：生活化比喻（能量高低=颜色）。

### 画像 2 研究生（+numerical / mechanism 定量）
- 「Dy³⁺ 的黄蓝比怎么影响白光色温？」→ 预期：黄蓝比高→色温低（暖白），给出调节方向。
- 「掺杂浓度一般超过多少会出现浓度猝灭？」→ 预期：给量级（mol% 级，因基质而异）。

### 画像 3 科研员（+formula / evaluation）
- 「临界距离 Rc 的计算公式是什么？」→ 预期：给出 Blasse 公式 Rc≈2(3V/4πx_cN)^{1/3} 或 Dexter 公式。
- 「磷酸盐和硅酸盐基质哪个更适合 Dy³⁺ 白光？」→ 预期：对比（磷酸盐价廉/硅酸盐稳定性），不答非所问。

### 画像 4 LED工程师（+numerical / comparison 应用）
- 「6500K 和 3000K 的白光 LED 哪个蓝光危害更大？」→ 预期：6500K 蓝光成分高、危害大，给低色温建议。
- 「CRI≥90 的白光方案怎么配荧光粉？」→ 预期：红光补偿（红粉+黄绿粉）应用建议。

### 画像 5 老师（+generation 导入语）
- 「写一段『4f 跃迁』的课堂导入语」→ 预期：结构化、含生活化引子（现有能力缺口，待验证）。

### 画像 6 爱好者（+mechanism 通俗）
- 「为什么有的荧光粉发红光、有的发蓝光？」→ 预期：通俗（不同元素/能级差=不同颜色）。

### 画像 7 博士生（+numerical / comparison 深挖）
- 「上转换量子产率通常是什么数量级？」→ 预期：给量级（普遍 <1%，核壳可提升），诚实说明。
- 「光子雪崩和能量迁移上转换有什么区别？」→ 预期：机制对比（阈值 vs 梯度）。

### 画像 8 技术员（+numerical 参数）
- 「XRD 物相扫描的角度范围一般设多少？」→ 预期：给典型参数（如 10°–80°，步长 0.02°）。

### 画像 10 采购（+evaluation 选型）
- 「YAG 荧光粉和 Dy³⁺ 荧光粉做白光哪个性价比高？」→ 预期：选型对比（YAG 成熟价廉/Dy 色温可调），给权衡。
