# 领域推演逻辑：可推演规则清单 + 推演能力契约

> 生成时间：2026-08-16
> 定位：系统目前只会「检索已知实例」（问「Dy 蓝光黄光跃迁」→ 查到 tf-dy-01/02 里写好的答案）。
> 但「114+256」这类问题，靠的是**规则推演**——有「加法规则 + 数字」就能推「任意和」，
> 而不是「只记得 1+1=2、1+2=3」。
>
> 本文档定义：发光材料领域里**哪些东西能推、怎么推、推到什么程度、推不了怎么诚实说**。
> 这是「推演引擎」的设计规格，实现前先推演验证（见文末）。

---

## 一、检索 vs 推演（为什么需要推演）

| | 检索（现状） | 推演（目标） |
|---|---|---|
| 问「4F9/2→6H15/2 能量差 2.58 eV，波长多少」 | 查「有没有 2.58 eV→480nm 这个实例」，没有就答不出 | 用 `λ = 1240/E` 推 `≈480nm`，不依赖实例 |
| 问「掺杂浓度超过临界会怎样」 | 查「浓度猝灭」的现成描述 | 用「浓度↑→间距↓→无辐射↑→效率↓」因果链推 |
| 换一种问法 | 可能匹配不到 → 答非所问/拒答 | 识别「规则」而非「词」，照样推 |

**核心**：推演 = `规则 + 已知量 → 未知结论`，不是「关键词 → 相似实例」。

## 三、推演能力契约（输入 → 期望 → 判定）

> 判定全走确定性规则（数值/关键词/因果链），零 LLM，可写成契约测试。

| 契约 | 输入（问法示例） | 期望推演结果 | 判定 |
|---|---|---|---|
| D1 数值推演 | 「4F9/2→6H15/2 能量差 2.58 eV，发射波长多少」 | ≈480 nm | answer 含 `480`（或 480±10） |
| D2 逆运算 | 「480 nm 的光子能量多少 eV」 | ≈2.58 eV | answer 含 `2.5` 或 `2.58` |
| D3 因果推演 | 「掺杂浓度超过临界会怎样」 | 发光效率骤降（浓度猝灭） | answer 含 `猝灭` 或 `效率`+`降/骤降` |
| D4 关系推演 | 「黄蓝比高，白光色温偏冷还是暖」 | 暖白（色温低） | answer 含 `暖` 或 `低` |
| D5 诚实边界 | 「只知道波长，没有能量差，能推出效率吗」 | 诚实说明推不了（缺已知量/规则不覆盖） | answer 含 `无法/缺/不足/推不出` 之一 |

## 四、推演边界与诚实（关键）

**能推**：命中规则 且 已知量足够（如 A1 有 ΔE 就能推 λ）。

**不能推**：
1. 缺已知量（A1 只有波长、没给 ΔE，且没别的约束 → 推不了）；
2. 规则不覆盖（问「某材料的发射峰形状」无规则 → 不推）；
3. 超出领域（问「天气」→ 不推，走诚实拒答）。

**三个补充边界（推演 2 遍后确认）**：
- **可逆性**：B1 等因果链支持逆推（浓度↓ → 间距↑ → 无辐射↓ → 效率↑），规则要写成双向。
- **定性 vs 定量**：C2「黄蓝比高→色温低」只能定性推方向，推不了具体色温 K（那需要更细的谱数据），要明确标注。
- **公式 vs 数值**：A3 这类「含基质参数」的公式，只给公式 + 说明需要的已知量，不硬凑数值。

**诚实原则**：推不了就明说「缺哪个已知量 / 无对应规则」，**绝不编造数值或结论**。
这比「硬检索一个近似实例来凑答案」更诚实——凑答案是张冠李戴的隐患。

## 五、推演验证（写码前先自测 2 遍）

### 第 1 遍 · 正向推演（标准实例，验证结果正确）
- A1：ΔE=2.58 eV → 1240/2.58 = 480.6 ≈ 480 nm ✓
- A2：480 nm → 1240/480 = 2.583 eV ✓
- A3：⚠️ 定位问题 —— x_c/V/N 是基质参数，用户通常不给，实际是「给公式」而非「代入推数值」
- B1：浓度↑→间距↓→无辐射↑→效率↓ ✓（问「超过临界」→「效率骤降」）
- B2：温度↑→声子↑→效率↓ ✓
- B3：宇称禁戒→谱线窄+波长稳定+寿命长 ✓
- B4：反斯托克斯→低能激发→高能发射 ✓
- C1：蓝光+黄光→白光 ✓
- C2：黄蓝比高→色温低 ✓
- C3：Eu红/Tb绿/Dy蓝黄白 ✓
- C4：高色温→蓝光高→危害↑ ✓

### 第 2 遍 · 边界/反例推演（换问法、缺已知量、定量边界、反例）
- A1 缺已知量：问「4F9/2→6H15/2 波长多少」（没给 ΔE）→ 推不了 → 需诚实「缺能量差」
- A1 变体：问「2.58 eV 对应什么波长」→ 识别「2.58 eV」为 ΔE → 同样推 λ ✓
- A3 定量边界：问「Rc 是多少」→ 无 x_c/V/N → 只能给公式，不能给数值
- B1 可逆性：问「浓度降低会怎样」→ 逆推「效率恢复」→ 规则需支持双向
- C2 定量边界：问「黄蓝比 3:1 色温多少 K」→ 只能定性（高→低），推不了具体 K
- 反例：问「发射峰形状」→ 无规则 → 推不了 → 诚实
- 反例：问「天气」→ 领域外 → 诚实拒答

### 推演结论（修订后实施）
1. A3 定位为「公式展示」：给公式 + 说明需要 x_c/V/N，不硬凑数值。
2. 每条数值规则标注「已知量依赖」，缺了就诚实说明「缺哪个量」。
3. B1 因果链写成双向（可逆）。
4. C2 标注「只定性推，定量色温 K 推不了」。
5. 契约 D5 覆盖「缺已知量 / 无规则 / 领域外 → 诚实说明」。
