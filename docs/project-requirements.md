# 项目要求锚点（Project Requirements Anchor）

> 生成时间：2026-08-16
> 用途：钉死「我们这个项目要什么、不要什么」。以后被泛化要求带偏时，翻这一份回得来。
> 一句话：**在稀土（Dy/镝）垂直领域内，把多智能体协同 + 画像适配 + 诚实防幻觉 + 推演做到极致。**

---

## 一、定位（不可漂移）

- **项目名**：「绿色健康照明用发光材料的多智能体协同交互系统」
- **领域**：Dy（镝）/ 稀土发光材料，**垂直领域，不跨领域**
- **交付**：上海云之脑智能科技有限公司

> ⚠️ 明确排除：本项目**不是**「通用技能培训平台」，不覆盖「智能制造 / 工业互联网 / 软件开发 / AI」等跨垂直领域。
> 那些是泛化平台的要求，不是我们的。我们选的就是「稀土发光材料」这一块，深耕。

---

## 二、三支柱 + 三硬指标（唯一验收口径）

| 支柱 | 硬指标 | 目标 | 现状 |
|---|---|---|---|
| 能力覆盖 | 知识点覆盖率 | ≥90% | ✅ 100% |

## 三、「学习者适配」的正确定义

是 **Dy 领域内**的不同背景学习者，不是「跨领域」背景。

**10 画像**（身份 × 能力 × 方向 × 态度）：
小白本科生 / 研究生 / 企业科研员 / LED 器件工程师 / 材料课老师 / 跨专业爱好者 / 博士生 / 实验室技术员 / 大四待就业 / 企业采购。

适配手段（已落地）：难度适配（θ→ZPD）、通俗化按画像自动降级、bloom 目标、学习风格。

---

## 四、「场景覆盖」的正确定义

不是跨到别的行业，而是 **Dy 领域内的四大场景全覆盖**：

- 机理（能级跃迁、浓度猝灭、能量传递、热猝灭）
- 制备（高温固相、共沉淀、溶胶凝胶、水热）
- 表征（XRD、PL、SEM/TEM、ICP-OES）
- 应用（白光 LED、健康照明、蓝光危害、显色）

对应 42 个 KP（A理论 / B材料 / C制备 / D表征）——已铺满。
