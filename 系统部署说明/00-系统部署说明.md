# 系统部署说明

> 适用对象：评审 / 部署人员
> 适用范围：`dy3-polaris-source/`（完整源码 + 领域知识快照）
> 本文档所述步骤均以源码内脚本与配置文件为准，实测入口为 `http://localhost:8000/`。

---

## 一、包内文件

| 文件 | 用途 |
|---|---|
| `一键启动.bat` | 一键启动脚本（与源码根目录同一份），自动探测 Python、首启装依赖、启动服务并打开浏览器 |
| `.env.example` | LLM 接入配置模板（**不含任何密钥**）；需要外部大模型时复制为 `.env` 后填写 |
| `pyproject.toml` | 项目元数据与**依赖清单**（pip 安装时以此解析，无需手工逐个装） |
| `00-系统部署说明.md` | 本文档 |

> 源码本体在交付目录的 `dy3-polaris-source/` 中（含知识快照与 189 个 pytest 用例），不在本说明包内重复。

## 二、运行环境要求

- 操作系统：Windows 10/11（脚本为 Windows `.bat`，已在 Windows 11 实测）
- Python：**3.10 或更高**（`pyproject.toml` 声明 `requires-python = ">=3.10"`）
- 网络：首次安装依赖需要联网（脚本默认走清华 PyPI 镜像 `https://pypi.tuna.tsinghua.edu.cn/simple`）
- 大模型：**非必需**。不配置任何 Key 系统也能启动；问答请求会走配置的 provider，无可用 Key 时返回降级说明而非编造内容（该行为有对应测试用例覆盖）。

## 三、部署步骤

### 方式 A：一键启动（推荐）
1. 将 `dy3-polaris-source` 整个文件夹放到任意位置（无写死路径，可整体移动）。
2. 双击 `dy3-polaris-source\一键启动.bat`。
3. 脚本会自动：探测 Python（优先使用该目录/上一级目录的 `.venv`，其次系统 `python`/`py`）→ 首次自动执行 `pip install -e ".[dev]"` → 后台启动服务 → 打开浏览器。

### 方式 B：手动启动
```bat
cd /d dy3-polaris-source
pip install -e ".[dev]" -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m dy3_polaris.main --port 8000
```
然后浏览器访问 `http://localhost:8000/`。

### 停止服务
关闭标题为 `Dy3-Polaris 服务` 的命令行窗口即可。

## 五、配置外部大模型（可选）

1. 复制 `dy3-polaris-source\.env.example` 为 `dy3-polaris-source\.env`。
2. 按文件内注释选择 provider 并填写：
   - 云端服务：`DY3_LLM_PROVIDER`（deepseek / kimi / qwen / zhipu 等）+ 对应 `DY3_LLM_*_API_KEY`；
   - 本地免 Key：Ollama（如 `DY3_LLM_PROVIDER=ollama` + `DY3_LLM_BASE_URL=http://localhost:11434/v1` + `DY3_LLM_MODEL=...`）。
3. 保存后重启服务即生效（无需重装依赖）。

> 安全提醒：`.env` 含密钥，已被 `.gitignore` 排除，**不要**把它随目录分享/上传。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 端口 8000 被占用 / 页面一直转圈 | 用 `--port` 换端口（如 8001），浏览器访问对应端口；或先关闭旧的 `Dy3-Polaris 服务` 窗口 |
| 依赖安装失败 | 检查网络后重试；或换镜像 `pip install -e ".[dev]" -i https://mirrors.aliyun.com/pypi/simple` |
| 答非所问 / 提示不可信 | 系统内置「科学审核 / 幻觉防范」链路，对超出知识库或证据不足的问题会返回降级提示；请先确认 `.env` 已配置可用的大模型 |
| 演示账号画像被改写 | 在 `dy3-polaris-source` 执行 `git restore .`（种子账号文件已纳入 git 管理） |
| GitHub 网页打不开 | 网络原因（github.com 在国内常超时），仓库已同步上传：<https://github.com/Ymr-git/dy3-polaris-source>（main，commit `08686da`）；离线用本地文件即可 |
