# 测试数据清单

> 本包汇集随系统源码交付的**测试用例、评测基准、评测报告、真机验证记录与演示数据**。
> 每条均标注来源目录；除编排目录外**未对数据内容做任何修改**。
> 知识快照与语料不在此包（已随 `dy3-polaris-source/` 交付，见「系统部署说明」）。

## 使用方式

- **自动化用例**：进入 `dy3-polaris-source` 执行 `python -m pytest tests/ -q`；配置了外部大模型（`.env`）后结果更完整。
- **报告类数据**：JSON / HTML 直接用浏览器或编辑器打开；截图可对照「设计图目标规格-OCR提取.md」核对界面实现。
- **种子数据**：需要恢复出厂学情时，把 5 个 json 放回 `dy3-polaris-source\src\dy3_polaris\l2\data\learners\`（或在源码目录执行 `git restore .`）。

## 数据来源说明（实事求是）

- 01 / 02 / 06：直接取自当前交付源码 git 仓库（commit `08686da`）的受版本管理文件。
- 03 / 04 / 05：取自竞赛工作目录中的评测与真机验证产出（`qa/`、`05-验证/`、运行轨迹转存），为历次真实运行写入的结果文件；内容以各文件内部记录为准，本清单不做二次加工。
